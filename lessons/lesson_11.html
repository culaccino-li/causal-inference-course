预测问题与因果问题在估计什么？

预测模型

给定 X，预测观察到的 Y；可以利用与Y相关的所有信息，但容易学到处理选择机制。

因果模型

比较同一类人在D=1与D=0时的潜在结果，必须说明反事实如何识别。

预测：E[Y|X]　　因果：E[Y(1) − Y(0)|X]
优秀的分类器可能仅仅擅长判断“谁会被政策覆盖”，而不是“政策对谁有效”。

三个因果估计目标不能混成一个

ATE · 平均处理效应

E[Y(1)−Y(0)]；总体平均政策效果。

CATE · 条件处理效应

τ(x)=E[Y(1)−Y(0)|X=x]；不同人的政策响应。

政策价值 · Policy value

E[Y(π(X))]；在规则 π 下的总体结果，并可能加入成本与公平约束。

CATE大，并不意味着将该人纳入政策一定最优；需要考虑成本、可操作性与公平约束。

识别仍从潜在结果开始

Y = D · Y(1) + (1−D) · Y(0)

一致性与处理定义

政策版本必须清楚；同名政策的多种实现方式可能违反一致性。

可忽略性（观察研究）

{Y(0),Y(1)} ⟂ D | X，且X应为处理前变量。

共同支撑

0 ＜ P(D=1|X=x) ＜ 1，至少在目标总体的关键区域内。

随机实验有随机化保障；观察研究需要对这些识别条件进行实体论证。

为什么普通“机器学习残差回归”还不够？

同一样本过拟合

高灵活度学习器可能把噪声记成规律，导致残差相互依赖和偏误。

正则化偏误

即使在训练外，机器学习估计的辅助函数也带误差；直接代入传统公式可能使θ的推断偏离。

DML通过正交得分与样本拆分应对这些问题，但仍需辅助学习器达到适当误差速率。

交叉验证与交叉拟合有什么不同？

Cross-validation

主要目的：选择预测模型的超参数，估计样本外预测误差。

Cross-fitting

主要目的：为每个观测生成样本外辅助函数预测，计算正交估计方程。

二者可以结合：在训练折内调参，再对留出折生成预测。不能用最终测试折反复调模型。

DML的核心：Neyman正交得分

ψ = (D−e(X)) · [Y−m(X)−θ(D−e(X))]

正交性直觉

在正确辅助函数附近，对其中一个辅助估计的小扰动，得分的期望一阶变化为0。

统计作用

常使残余偏差主要依赖辅助函数误差的乘积，而非各自的一阶误差。

正交≠无偏万能：仍须处理外生性、重叠、样本大小、依赖结构与误差收敛条件。

DML的三步估计逻辑

① 先识别

明确D、Y、合适的前处理X与目标参数。

② 交叉拟合

在训练折预测m̂(X)、ê(X)。

③ 残差化

计算ỹ=Y−m̂(X)，đ=D−ê(X)。

④ 求解θ

将ỹ对đ回归，使用适当的标准误。

完整推断以正交得分理论为基础，不能只照搬最后一步的OLS命令。

为什么说是“二阶误差”？

主要交叉项

若辅助函数误差分别为aX和bX，正交得分下出现近似a·b形式的偏误项。

但仍有二次项

对PLR残差回归，还存在与θ·b²相关的项；当误差很大时，不能指望近似成立。

示意偏差 = [a·b − θ·b²] / [1+b²]
上式仅对应上一页特定合成生成机制，不是所有DML模型的通用有限样本公式。

AIPW：如何实现双重稳健？

φ = μ₁−μ₀ + D·(Y−μ₁)/e − (1−D)·(Y−μ₀)/(1−e)

重要性质

在识别假设和常规条件下，倾向得分模型或结果模型之一正确时可得到一致的ATE。

依然存在的风险

若e接近0或1，权重可能爆炸；若识别失效，统计意义上的双重稳健无能为力。

DML强调正交性与交叉拟合；AIPW是可用于ATE的正交得分构造之一。

政治学用途

为什么“变量重要性”不是机制证据？

变量重要 ≠ 因果机制

能帮助模型划分效应异质性的变量，未必是政策发生作用的中介。

机制需要新假设

即使对处理前X发现效应不同，也需额外理论、排除限制或机制实验才能解释传导通道。

Fu & Slough（2026，APSR）指出：仅凭异质效应来论证机制，在理论上往往需要额外的排除假设。

与DID、RDD、IV怎么结合？

DID + ML

机器学习可用于处理前协变量的结果/倾向模型；需兼容组时间ATT与相关依赖推断。

RDD + ML

在阈值附近用于灵活协变量调整和精度改善，但不能更改断点设计的识别逻辑。

IV + ML

可学习工具变量或结果辅助函数，使用正交估计；排除限制和弱工具问题仍须论证。

组合方法的关键是“把学习器放在正确的辅助步骤”，不是用黑箱替代识别假设。

R：可运行的 grf 异质效应示例

R / grf · 合成RCT、ATE、CATE校准
## 首次使用: install.packages("grf")
library(grf)
set.seed(2026)
n <- 1000
X <- cbind(rnorm(n), rnorm(n), rnorm(n))
W <- rbinom(n, 1, 0.5)  # 随机处理
true_tau <- 1 + X[, 1]
Y <- X[, 2] + W * true_tau + rnorm(n)

forest <- causal_forest(X, Y, W, num.trees = 2000)
ate <- average_treatment_effect(forest)
cate <- predict(forest)$predictions
print(ate)
print(test_calibration(forest))
print(best_linear_projection(forest, X[, 1:2, drop=FALSE]))
plot(X[, 1], cate, pch=16, cex=.4,
     xlab="处理前 X1", ylab="预测CATE")
这段代码使用模拟的随机实验。CATE不是单位可观察的个体真效应；校准检验比仅看一张散点图更重要。

R：简洁展示两折交叉拟合PLR

R / 正交残差 + 样本外辅助函数预测（线性学习器示范）
set.seed(11)
n <- 1200
x1 <- rnorm(n); x2 <- rnorm(n)
D <- 0.7*x1 - 0.3*x2 + rnorm(n)
Y <- 2*D + sin(x1) + x2^2 + rnorm(n)
dat <- data.frame(Y, D, x1, x2)
fold <- sample(rep(1:2, length.out=n))
mhat <- ehat <- rep(NA_real_, n)
for(k in 1:2) {
  tr <- fold != k; te <- fold == k
  fitY <- lm(Y ~ x1 + x2 + I(x1^2) + I(x2^2), dat[tr,])
  fitD <- lm(D ~ x1 + x2 + I(x1^2) + I(x2^2), dat[tr,])
  mhat[te] <- predict(fitY, dat[te,])
  ehat[te] <- predict(fitD, dat[te,])
}
# 仅为PLR演示；IID数据、简单线性学习器
summary(lm(I(Y-mhat) ~ 0 + I(D-ehat)))
完整的DML推断请使用有正交得分理论与有效标准误实现的专门软件，而非把上例的lm标准误直接当作通用保证。
