潜在结果与实验估计对象

ATE

E[Y(1)−Y(0)]：目标总体平均因果效应。

ITT

E[Y | Z=1]−E[Y | Z=0]：按分配组比较。

CACE / LATE

随机鼓励下，针对顺从者的局部处理效应；额外依赖IV假设。

τITT = E[Y | Z=1] − E[Y | Z=0]

完全随机、区组与分层随机化

完全随机

适合样本数量足够、实施简单的场景；需明确固定组数或伯努利分配。

区组/分层

在地区、历史投票率等分层内部进行随机分配，提高重要协变量的可比性。

配对随机

按相似单位配对，每对随机分派一个处理；分析需尊重配对结构。

整群随机化：个体还是社区？

个体随机化

统计效率往往更高，但同一社区内易出现交叉接触与污染。

整群随机化

适合学校、社区、村庄整体实施，但同群结果相关，标准误和功效必须调整。

DE ≈ 1 + (m − 1)ρ

政治学案例：社会压力能动员选民吗？

Gerber、Green 与 Larimer（2008），American Political Science Review 102(1):33–48。

在美国密歇根初选前向数十万登记选民随机寄发不同内容邮件，比较选举参与。

研究发现在承诺公布家庭或邻居投票纪录的组别中，投票率有明显提升。

clear all
set seed 2026
set obs 400
* 完全随机分配；教学数据，不是论文数据
gen id = _n
gen u = runiform()
sort u
gen Z = (_n <= 200)
gen age = round(rnormal(45, 13))
gen y = (runiform() < invlogit(-1 + .38*Z + .012*age))
reg y Z, vce(robust)

R｜随机化与意向处理

R · 教学代码
set.seed(2026)
n <- 400
z <- sample(rep(c(0, 1), each = n/2))
age <- round(rnorm(n, 45, 13))
y <- rbinom(n, 1, plogis(-1 + .38*z + .012*age))
d <- data.frame(z, age, y)
# 意向处理：按随机分配组比较
with(d, tapply(y, z, mean))
summary(lm(y ~ z, data = d))
