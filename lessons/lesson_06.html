01 / MOTIVATION

为什么不能直接比较政策前后？

某地实施一项政策后，选民支持率提高了。

但与此同时，全国政治氛围、经济环境与其他事件也可能发生变化。

政策后 − 政策前，既包含政策可能造成的效应，也包含共同时间变化。

01 / LEARNING TARGETS

本讲的三个关键问题

反事实来自哪里？

用未处理地区的变化，预测处理地区“若未实施政策”的结果。

平行趋势为什么关键？

需要比较的是未接受政策时的趋势，而不是两组的水平必须相同。

现代DID为什么不同？

实施时间错位、效应异质性会使传统双向固定效应产生不易解释的比较。

02 / THE TWO-BY-TWO

一个标准的 2 × 2 研究设计

群体政策前 t=0政策后 t=1
处理组 D=14052
对照组 D=03542

演示数字为教学设定，单位：结果变量分值。

处理组变化：52 − 40 = 12

对照组变化：42 − 35 = 7

两组的变化之差为 12 − 7 = 5。只有在适当假设下，这才是政策效应。

02 / FORMULA

第二重差分：扣除共同变化

ΔT = E[Y|D=1, post] − E[Y|D=1, pre]
ΔC = E[Y|D=0, post] − E[Y|D=0, pre]
DID = ΔT − ΔC = (52−40) − (42−35) = 5
通过对照组的变化估计“没有政策时处理组会如何变化”，再从实际变化中扣除这一反事实趋势。
02 / TARGET PARAMETER

DID 估计的是什么？

经典2×2 DID主要识别 ATT（已处理群体的平均处理效应）。

它并不自动识别对照组的政策效应，更不必然等于所有地区的 ATE。

先明确“对谁、在哪个时期”的政策效应，再决定比较方式。

潜在结果表达

ATT = E[Y1(1) − Y1(0) | D=1]

我们观察得到 Y₁(1)，却无法直接看到同一处理组的 Y₁(0)。DID利用对照组趋势构造后者。

03 / PLACEBO INTUITION

把“真实效应”设为零会怎样？

如果两组在没有政策时仍有不同趋势，即使真实政策效应为零，DID也可能观察到非零估计值。

这说明DID不仅需要“前后”和“处理对照”四格数据，还需要可信的制度背景与识别假设。

回到前一页，将真实效应设为0，再调节额外趋势偏离，观察虚假政策效应。

偏差分解

DID = ATT + 趋势偏差

在这一教学设定中，趋势偏差等于处理组未处理趋势额外偏离的参数。

这不是任何DID估计都能直接观察到的分解；现实中的反事实趋势通常不可见。

04 / PARALLEL TRENDS

平行趋势：真正的识别假设

E[ΔY(0)|D=1] = E[ΔY(0)|D=0]

比较的是“变化”

处理组与对照组的结果水平允许不同。关键在于：没有政策时，两组的平均变化应相同。

比较的是 Y(0)

政策后处理组的无政策潜在结果不可直接观测，因此平行趋势本质上是一个不可完全检验的反事实假设。

04 / MISCONCEPTION

平行趋势并不意味着水平相等

处理组与对照组可以一开始就存在很大差距。

只要它们在没有政策时，随时间的增量相同，DID的反事实逻辑仍可能成立。

平行≠重合：允许不同截距，但不能任意允许不同未处理斜率。

04 / INFERENCE

政策前“没显著趋势”，并不等于安全

统计功效问题

政策前样本小或噪声大时，显著性检验可能很难发现真实存在的趋势差异。

政策后不可见

即便前期趋势看起来接近，也不能据此逻辑证明政策后反事实会一直平行。

更完整的论证

要结合制度背景、处理时间、政策前走势、安慰剂检验、替代对照和敏感性分析。

04 / IDENTIFICATION

没有预期效应与溢出效应

No anticipation

个体不能在政策正式实施前，因预期政策而提前改变结果。否则“政策前”已经受影响。

No spillovers

对照组不应因处理组政策而系统性改变潜在结果。跨区迁移、舆论扩散可能破坏此条件。

稳定构成

若处理改变样本进出、统计口径或人口结构，观察到的变化可能包含构成效应。

05 / REGRESSION

从面板固定效应走向DID

Yit = αi + λt + τDit + εit

αᵢ

个体固定效应：控制单位不随时间变化的加性特征。

λₜ

时间固定效应：控制各单位共同面对的加性时间冲击。

τ

两组两期经典设定下的DID交互效应；不意味着所有多期分期模型中都可直接解释为ATT。

05 / 2×2 REGRESSION

两组两期：交互项就是双重差分

Y = β₀ + β₁Treat + β₂Post + τ(Treat×Post) + ε
这四格均值对应一个饱和的2×2模型。交互项 τ 正好等于两组前后差分的差。
标准误需根据处理分配和重复观测结构处理，尤其关注在群组层面实施政策时的群组内相关。
05 / INFERENCE

标准误：为什么不能只看系数？

聚类相关

同一地区在不同年份的残差可能相关，常需在政策分配的合理层级进行聚类。

群组数太少

少量处理地区时，常规聚类标准误可能不可靠；考虑适合设计的随机化推断或稳健方法。

敏感性

估计不确定性不仅来自抽样误差，还来自平行趋势等识别假设的脆弱性。

06 / EVENT STUDY

事件研究：让政策效应按时间展开

Yit = αi + λt + Σk≠−1 βk 1[t−Gi=k] + εit
相对政策时间 k=−1 通常作为基准期。系数可以描绘政策前的模式和政策后的动态变化，但在错位实施且效应异质时，传统TWFE事件研究系数可能受到混杂污染。

06 / CHECKS

DID的三个常见稳健性环节

安慰剂检验

将虚假实施日期提前，或在理论上不应受影响的结果变量上重复分析。

对照组敏感性

更换合理的对照地区、排除地理邻近溢出区域、检查处理前长期模式。

趋势假设敏感性

明确在“有限偏离平行趋势”时，结果会变化多少，不要只看前趋势p值。

07 / FORBIDDEN COMPARISONS

早处理组何时不能再当“对照”？

第4期后，早处理 E 与晚处理 L 都已经受到政策。

如果用早处理 E 的后续变化，去代表晚处理 L 的无政策趋势，就可能把 E 自己不断演变的政策效应混进估计。

已处理 ≠ 未处理对照。

07 / TWFE PITFALLS

为什么TWFE不总能给出想要的ATT？

比较被混合

传统TWFE利用所有随处理状态变化形成的比较，包括早期处理者与晚期处理者的比较。

异质性问题

群组间或政策实施后不同年份的处理效应可能不同，传统回归系数的隐含权重不一定符合研究目标。

先定义参数

明确要估计群组×年份 ATT(g,t)、动态效应，还是某种按群组与时间聚合的平均效应。

07 / GROUP-TIME ATT

ATT(g,t)：现代DID的基本积木

ATT(g,t)= E[Yt(g)−Yt(0) | G=g]

g 是首次处理时间

将首次在第g期接受处理的单位视为同一 cohort；t 是要评估其效应的时期。

使用合适的对照

可以选择从未被处理的群组，或在 t 时尚未被处理的群组，条件仍取决于可比性假设。

07 / ESTIMATORS

现代估计方法如何对应不同问题？

Callaway & Sant’Anna (2021)

分别估计群组—时间ATT(g,t)，再按目标聚合；允许处理时间错位和处理效应异质。

Sun & Abraham (2021)

构建更稳健的事件研究动态效应估计，避免传统TWFE leads/lags的异质性污染。

Borusyak et al. (2024)

利用未处理观测估计反事实，再对已处理观测做插补，并据此构造目标效应。

07 / METHOD CHOICE

一张方法选择路线图

两组两期

先使用直观的2×2 DID，并充分论证反事实平行趋势。

多期、同年实施

事件研究可追踪动态效应；认真评估政策前趋势与长期效应。

分期实施

优先根据ATT(g,t)或相应目标效应选择异质性稳健估计方法，避免机械使用TWFE。

估计量越复杂，不意味着因果识别假设越可信；应先明确设计与目标效应。
07 / WHY MODERN DID

现代DID的更新究竟在解决什么？

01比较不干净

早处理组后来也受政策影响，不能总当作未处理对照。

02效应不恒定

不同地区、不同暴露年份可能产生不同效应。

03反事实不确定

平行趋势可能只是近似成立，而非精确成立。

04政策不是二元

补贴额度、污染强度、救助规模有连续强度。

现代方法不是“替代DID”，而是要求先写清目标ATT、有效对照组及识别假设，再选合适的估计量。

07 / GOODMAN BACON

分期DID为什么会出现“坏比较”？

TWFE ≈ 多个2×2 DID的加权组合
A早期 vs 尚未处理

晚处理组在处理之前，可能提供有效对照。

B晚期 vs 已经处理

早处理组政策效应仍在变化，可能污染比较。

关键认识

单个TWFE系数不是自然的“所有人平均政策效应”。权重、实施时间和效应异质性共同决定它识别什么。

当处理效应随时间增长时，“已处理者作为对照”尤其危险。

07 / ALTERNATIVE ESTIMATORS

四种现代DID：应该在什么情况下使用？

CS / JoE 2021

ATT(g,t)

对首次处理于g期的群组，在t期分别估计ATT，再明确权重做聚合。

更适合：分期实施，关注组别与相对时间异质性。

SA / JoE 2021

Interaction-weighted event study

先构建群组×相对时期效应，再以清晰权重聚合，避免传统lead/lag污染。

更适合：关心政策动态及实施时点不同。

BJS / ReStud 2024

Imputation estimator

仅用未处理观测估计反事实结果，再对已处理观测的残差聚合。

更适合：分期采用、异质效应、事件研究。

Rambachan–Roth / ReStud 2023

Honest DID

放松精确平行趋势，限制政策后趋势偏离的范围并进行敏感性推断。

更适合：反事实趋势存在可信疑虑。

07 / CONTINUOUS DID

政策强度不是0/1：连续处理DID

“救助金额增加一万元，投票率提高多少？”

二元DID研究有无政策，连续DID还要研究剂量差异。不同强度群体的效应比较，可能混入对政策强度的选择。

平行趋势可以识别某些剂量下的处理效应，但并不自动识别跨剂量的纯粹因果差异或线性“每单位剂量效应”。

应该明确三个目标

1. 某剂量组相对于无政策的效应

2. 不同剂量的因果反应函数

3. 政策强度增加的边际效应

08 / DID + WEIGHTING

DID + 匹配/IPW：改变可比性，不创造外生性

先处理基线差异

匹配 / PSM

在政策前利用地理、经济、人口特征构造更可比的地区对；再对匹配样本计算DID。

风险：匹配只处理可观测差异，目标群体也可能变化。

利用倾向得分加权，或结合结果模型与权重构造双重稳健DID。

风险：仍需要条件平行趋势、重叠等条件。

DR DID：Outcome regression + Propensity score weighting

08 / DDD

三重差分 DDD：再扣掉一个偏差来源

DDD = DID目标人群 − DID对照人群

例如：只对符合年龄条件的居民实施补贴；同时观察符合与不符合条件人群在不同地区的政策前后变化。

需要的是“两个DID的反事实偏差之差”为零的相关条件；并非机械要求两个DID各自都完全平行。

论文DAG：灾害、政策响应与选举

洪灾冲击 F 会影响政府救助 R，也可能直接影响政治关注、经济损失与投票行为 Y。

论文识别：平行趋势的政治学含义
