01 / MOTIVATION

选举只差一票：比较谁？

候选人A以 50.1% 的得票率险胜，候选人B以 49.9% 险败。

两人的政治资源、历史基础可能不同；但在50%门槛附近，微小得票差距是否提供了一种更可信的比较？

RDD把识别焦点放在阈值两侧非常接近的单位，而不是比较所有胜者与败者。

01 / THREE INGREDIENTS

RDD 研究设计的三个组成部分

运行变量 X

可排序的分数：选举得票差、考试分数、申请评分、年龄等。

阈值 c

政策规则发生变化的位置，如50%得票率、最低录取线。

分配规则 Z

Sharp RDD：Z=1(X≥c)；Fuzzy RDD：门槛仅改变实际处理概率。

02 / ESTIMAND

RDD 识别的是一个局部处理效应

τRD = limx↓c E[Y|X=x] − limx↑c E[Y|X=x]

阈值右极限

从已处理侧无限接近 c 的条件结果均值。

阈值左极限

从未处理侧无限接近 c 的条件结果均值。

在相关潜在结果条件期望于 c 连续等条件下，这个差值可以解释为阈值处的平均因果效应；并不自动代表全体样本的 ATE。
03 / IDENTIFICATION

连续性假设：不可直接观察的核心

不实施处理时，结果变量的潜在趋势不应在 c 处自行跳跃。

形式上，E[Y(0)|X=x] 与 E[Y(1)|X=x] 在门槛处应连续。

在门槛处观察到的 Y 跳跃，才可归因于处理状态的突然变化。

03 / CAUSAL STRUCTURE

RDD 的 DAG：门槛提供什么信息？

运行变量 X 会影响是否越过门槛 Z，也往往连续地影响结果 Y。

只要这些背景因素在门槛附近没有自身的不连续跳跃，比较两侧极限可隔离 Z 的效应。

RDD不是“随机控制 X”；关键是 X=c 附近对潜在结果的连续性约束。
03 / LOCALITY

断点附近 ≠ 整体可交换

识别范围局部

因果解释主要针对 X≈c 的群体；远离阈值的单位可能不同。

没有精确操纵

利益相关者不能精确把自己安排到有利的阈值侧。

其他机制不突变

同一阈值不能同时触发多个无法分离的政策变化。

04 / LOCAL POLYNOMIAL

全样本拟合为什么可能误导？

结果与评分 X 的关系可能弯曲。强行让全范围的数据共用简单线性趋势，就可能把曲率错当为政策效应。

现代RDD更偏好门槛两侧分别做局部低阶多项式。

04 / LOCAL LINEAR

局部线性回归：门槛两侧分别拟合

Yᵢ = α + τZᵢ + β₁(Xᵢ−c) + β₂Zᵢ(Xᵢ−c) + εᵢ

分侧斜率

X-c 与 Z×(X-c) 允许门槛两侧斜率不同。

窗口约束

仅使用 |X-c|≤h 的观测，必要时再赋予距离权重。

解释位置

τ 是 c 处的条件均值差，不是任意远距离两单位的差。

04 / TRADEOFF

带宽选择的偏差—方差权衡

带宽太窄

可用样本减少，估计波动大；可能难以识别稳定趋势。

带宽太宽

会纳入距阈值较远的观测，模型近似偏差可能升高。

实践方案

报告数据驱动带宽、稳健偏差修正区间，并预先指定合理的带宽敏感性检验。

05 / INFERENCE

图形呈现不是显著性检验

可视化

RD 图通常将运行变量分箱展示均值，并叠加两侧拟合曲线；分箱是展示选择，不等于估计窗口。

正式推断

使用局部多项式、数据驱动带宽、稳健偏差修正（RBC）置信区间；同时检查有效样本与支持范围。

不能靠“肉眼看似跳跃”直接断定因果效应成立。
05 / ROBUST BIAS CORRECTION

RBC：为什么传统置信区间可能偏？

使用均方误差优化（MSE-optimal）的带宽时，传统局部多项式区间可能因平滑偏差而覆盖不足。

Calonico、Cattaneo与Titiunik（2014）提出偏差修正与匹配的稳健标准误估计。

点估计

局部低阶多项式估计 τ̂。

稳健区间

修正估计偏差，并调整标准误计算。

方法来源：Econometrica 82(6), 2295–2326 · DOI:10.3982/ECTA11757
06 / MANIPULATION

为什么阈值附近的数据密度值得检查？

如果研究对象能够精确选择“刚好越线”，阈值右边可能异常堆积。

密度不连续是一种对排序/操纵风险的诊断信号，但密度平滑也不能自动证明因果假设成立。

06 / VALIDATION

有效性诊断：需要报告什么？

密度检验

检查运行变量在阈值附近是否存在不寻常的分布跳跃。

预处理协变量

测试处理前特征在门槛两侧是否连续，避免只报告“成功”的指标。

安慰剂与稳健性

伪断点、替代带宽、局部多项式阶次、数据缺失与分数精度检查。

06 / COVARIATE CONTINUITY

对预处理变量做“伪结果”检验

真正的处理不能改变阈值前已发生的事实，例如候选人此前的从政经历、历史资源。

如果它们在门槛处已经跳跃，需重新检查排序、样本选择和函数形式。

06 / ROBUSTNESS

两个最容易被误用的稳健性检验

人为“空心”Donut RD

剔除阈值附近少量高风险点，检验结果是否由精确排序或测量问题驱动；但识别目标/有效样本随之改变。

伪断点 Placebo

在规则并未触发的评分位置重复估计，若同样出现跳跃，可能提示函数形式或其他断点的干扰。

诊断不能相互替代：无显著密度跳跃 ≠ 协变量必然平衡；协变量平衡 ≠ 排除所有未观测问题。
07 / FUZZY RD

模糊断点：越线不等于必然接受处理

达到最低资格线可能只使领取补助的概率从20%跳到80%。

即使存在不完全服从，阈值仍可作为一个局部工具变量。

07 / ADDITIONAL ASSUMPTIONS

模糊断点为什么不能直接当成 Sharp RD？

排除限制

门槛 Z 不能绕过实际处理 D 而直接改变结果 Y。

单调性

不存在因为越线反而拒绝处理的“反向服从者”。

足够强的第一阶段

如果处理概率的跳跃很小，Wald 比值不稳定，需要谨慎推断。

08 / METHOD COMPARISON

RDD 与 DID：为什么是不同的反事实？

RDD · 分数连续性

利用同一时点、阈值附近的两侧极限进行反事实比较，识别阈值附近效应。

DID · 趋势反事实

使用政策前后组间变化与平行趋势假设，识别特定处理群体/时期的效应。

可以结合：如果门槛规则在某时刻开始实施，比较门槛处的跳跃在政策前后如何变化，形成 Difference-in-Discontinuities；仍需额外识别假设。
08 / MODERN EXTENSIONS

RDD 扩展：局部随机化和离散分数

Local randomization

在足够窄、可辩护的邻域内，把分配近似当作随机，进行窗口选择、随机化推断、协变量平衡诊断。

Discrete running variable

如果分数只可能取少数整数，c 附近不能无限逼近；要讨论有限支持、窗口选择与额外模型假设。

Cattaneo、Idrobo与Titiunik（2024），Cambridge Elements · Extensions
08 / ADVANCED DESIGNS

地理断点、多阈值与 Kink RD

地理 RDD

边界两侧行政单位可能受到不同政策，但需警惕边界附近其他制度因素同时变化。

多断点 RDD

比较不同阈值、不同处理强度或不同人群，外推取决于附加结构假设。

Regression Kink

处理强度函数在门槛处斜率突变；识别对象是斜率变化比率，假设比 Sharp RD 更强。

核心问题：险胜/险败能否作为近似随机比较？

研究发现：作者在美国众议院不同历史时期、美国州与地方选举、其他九国选举等大量竞选样本中检查“在极接近的选举中现任党更可能获胜”的异常模式；除了特定时期的美国众议院选举，其他设置未发现类似模式。

09 / AJPS 2015 · PAPER 3/6

论文因果图：为何精确排序是威胁？

假设候选人原有资源 U 同时影响胜负分差 X与下一次选举结果 Y。

如果 U 还造成 X 在零点附近不连续的排序，险胜者与险败者就可能不是可比的。

DAG用于解释为何需要诊断；仅凭一张DAG不能证明阈值处连续性。
09 / AJPS 2015 · PAPER 4/6

论文的识别假设：不是“所有选举都随机”

支持RD可信度的条件

参与者可能影响胜率，但无法在已知全部不确定性下精确控制最终分差；需要检验阈值附近的可比性。

需要认真回应的反证

特定时期的美国众议院接近选举出现现任党险胜的异常模式；不能将这种发现无条件外推至其他制度环境。

与 Caughey & Sekhon（2011，Political Analysis）的批评形成研究对话：他们发现战后美国众议院险胜与险败候选人在处理前特征上有明显不平衡。

09 / AJPS 2015 · PAPER 5/6

论文估计与公式：区分诊断与效应估计

效应估计的一般形式

τ = limx↓0E[Y|X=x] − limx↑0E[Y|X=x]
在有效假设下，表示阈值处胜选状态对后续Y的局部因果效应。

这篇论文实际聚焦

选举接近零分差时的排序与有效性证据，而不是向全部选举给出一个统一的‘胜选处理效应’点估计。

应将 Lee（2008，Journal of Econometrics）的议员连任优势效应估计，与 Eggers 等（2015）的有效性检验区分为两篇不同研究。

10 / RESEARCH DESIGN

从论文到研究设计：六个质询

01阈值真实存在吗？

法律、选制或行政规则是否明确？

02谁能操纵分数？

精确操纵与制度安排如何运行？

03结果何时测量？

处理前后时间顺序能否站住脚？

门槛附近的人与一般人有多像？

11 / CODE · STATA

Stata：从可复现模拟到 rdrobust

Stata · 教学合成数据，非论文复现
* 如未安装：ssc install rdrobust
* 密度检验：net install rddensity, from(https://raw.githubusercontent.com/rdpackages/rddensity/main/stata) replace
clear all
set seed 1027
set obs 600
gen margin = 2*runiform() - 1
gen eligible = (margin >= 0)
gen outcome = 2 + .8*margin + .7*margin^2 + 2.5*eligible + rnormal()

rdplot outcome margin, c(0)
rdbwselect outcome margin, c(0)
rdrobust outcome margin, c(0)
rddensity margin, c(0)

* 模糊断点示例：处理概率随门槛跳跃
set seed 7
gen actual = (runiform() < cond(eligible==1,.80,.20))
gen outcome_f = 2 + .8*margin + 2.5*actual + rnormal()
rdrobust outcome_f margin, fuzzy(actual) c(0)

11 / CODE · R

R：估计、诊断与模糊断点

R · 教学合成数据，非论文复现
# install.packages(c("rdrobust", "rddensity"))
library(rdrobust)
library(rddensity)
set.seed(1027)
n <- 600
margin <- runif(n, -1, 1)
eligible <- as.integer(margin >= 0)
y <- 2 + 0.8*margin + 0.7*margin^2 + 2.5*eligible + rnorm(n)

rdplot(y, margin, c=0)
rdbwselect(y, margin, c=0)
summary(rdrobust(y, margin, c=0))
summary(rddensity(margin, c=0))

set.seed(7)
actual <- rbinom(n, 1, ifelse(eligible==1, .8, .2))
y_fuzzy <- 2 + 0.8*margin + 2.5*actual + rnorm(n)
summary(rdrobust(y_fuzzy, margin, fuzzy=actual, c=0))
