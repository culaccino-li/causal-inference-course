01 / QUESTION

为什么只比较国家之间的差异不够？

富裕国家往往民主程度较高。这个相关性可以说明：收入增加会带来民主化吗？

国家之间还不同于历史、制度、文化等长期因素。即使收入没有因果作用，也可能出现跨国相关。

面板数据允许我们追踪同一个国家自身随时间的变化。

01 / CORE IDEA

本讲要完成的三个判断

数据如何组织？

为什么同一国家在不同年份的观测，与每年抽取不同国家不是一回事？

固定效应消除了什么？

通过去均值，把始终不变的个体差异从估计中排除。

什么仍然威胁因果解释？

随时间变化的混杂、反向因果、共同趋势以及处理的动态效应。

02 / DATA STRUCTURE

Panel Data = 个体 × 时间

单位 i　×　时间 t

国家、城市、个人、企业都可以是 i；年份、季度或月份是 t。

同一单位被重复观测，形成以 (i,t) 标识的面板记录。

“面板数据”是一种数据结构，不等于“固定效应方法”，更不自动意味着因果识别。

02 / PRACTICAL DATA

宽表与长表：点击切换

长表：一行对应一个国家—年份；适合 xtset、固定效应回归与合并年度政策数据。

宽表：每个国家一行，不同年份为不同列；报告和手工查看方便，但通常需要 reshape。

分析前检查 (i,t) 是否唯一、年份是否连续、缺失值如何产生。
02 / TYPES

平衡面板、不平衡面板与重复截面

平衡面板 Balanced

每个单位在所有研究时期都有记录：例如100个地区×10年。

不平衡面板 Unbalanced

部分单位缺少年份。原因可能是样本进入、退出、失访或数据缺测。

重复截面 Repeated Cross-sections

各期抽到的可能不是同一批个体；不能直接对个人做个体固定效应。

03 / VARIATION

面板数据中有两种不同的比较

教学模拟 · 非论文原始数据

Between：不同国家的长期平均水平彼此不同。

Within：同一个国家在不同年份偏离自身平均值。

Xit = X̄i + (Xit − X̄i)
固定效应回归主要利用个体内部的 Within variation。
03 / ANIMATION

第一眼看到的是国家之间的距离

步骤 1：每个国家有不同的长期起点。

步骤 2：把每个国家的序列平移到自身零点。

步骤 3：比较去掉固定水平差异后的变化轨迹。

看原始水平：三国的长期差异非常明显。

04 / MODEL

个体固定效应 FE

Yit = βXit + αi + εit

αi：所有不随时间变化的、单位自身的因素

Xᵢₜ：随时间变化的解释变量

例如一个国家当年的收入水平、政策覆盖或失业率。

αᵢ：单位固定效应

例如研究期内不变的地理环境、历史遗产及稳定制度特征。

εᵢₜ：剩余冲击

其中若仍含同时影响X与Y的时变因素，FE也会有偏。

04 / WITHIN PROOF

去均值为什么能消除 αᵢ？

Yit = βXit + αi + εit
下一步：对每个 i 的时间序列求均值
Ȳi = βX̄i + αi + ε̄i
再相减
Yit − Ȳi = β(Xit − X̄i) + (εit − ε̄i)

关键是 αi − αi = 0。静态文字不逐条播放，仅推导步骤显示。

04 / IDENTIFICATION

FE 能去掉哪种遗漏变量？

如果稳定因素 Uᵢ 同时影响 X 和 Y，直接比较可能有混杂偏差。

只要 Uᵢ 在观察期内不变，个体固定效应会吸收其加性影响。

但是：FE 不会自动消除随时间变化的混杂 Uᵢₜ，也不能解决所有反向因果。
教学模拟 · 非论文原始数据
05 / TWO WAY FE

再加上时间固定效应

Yit = βXit + αi + λt + εit

αᵢ 消除单位不变因素；λₜ 消除同一时期所有单位共同受到的加性冲击。

国家固定效应 αᵢ

每个国家都有自己的截距；比较同一国家不同时期偏离自身均值的部分。

年份固定效应 λₜ

允许不同年份有共同截距，例如世界经济周期、共同国际冲击。

如果共同冲击对不同单位影响幅度不同，单纯的年份虚拟变量未必能充分调整。

05 / FIRST DIFFERENCES

两个时期下，FE 与一阶差分的关系

ΔYi = βΔXi + Δεi

一阶差分：对同一单位，直接计算第二期减第一期。

当所有单位只有两个时期、模型线性且使用相同数据时，一阶差分 OLS 的斜率与个体固定效应斜率相同。

超过两期时，FE 与一阶差分通常使用不同的加权信息，估计不一定相同。

05 / COMPARISON

Pooled OLS、FE、RE：不要混成一件事

Pooled OLS

将面板记录堆叠回归；若遗漏稳定单位差异且与 X 相关，可能产生偏误。

固定效应 FE

允许 αᵢ 与 Xᵢₜ 相关；主要依赖单位内部随时间变化的信息。

随机效应 RE

经典 RE 要求单位效应与协变量不相关（或采用相关随机效应扩展）；可以利用 between 和 within 信息。

05 / RE / HAUSMAN

Hausman检验不是方法选择的全部

传统 Hausman 检验比较 FE 与 RE 的系数差异，检验某些模型条件下的统计一致性假设。

但“显著就用FE、不显著就用RE”只是粗略做法：还要考虑理论上的单位效应与 X 是否相关、聚类推断、变量是否随时间变化等。

方法选择的第一步是理解估计来自哪里，不是机械地点击软件里的检验按钮。

不能忘记的问题

① 是否有足够的单位内部 X 变化？

② 样本是否发生选择性进入/退出？

③ 是否仍有时变混杂或反向因果？

④ 主要关注 within 效应还是 between 差异？

06 / ESTIMANDS

固定效应何时能有因果解释？

严格外生性（经典线性FE）

给定 αᵢ 与完整解释变量路径后，所有时期的误差期望为零。允许反向反馈时往往不成立。

充分的单位内部变化

如果 X 对一个国家十年完全不变，个体FE就无法从自身变化中识别其系数。

可解释的处理效应

对于具有复杂动态效应的政策处理，线性TWFE系数未必是简单的ATE；应说明估计对象和识别假设。

06 / LESSON FROM THE LAB

理解三种常见偏差机制

只改变单位长期差异

增大 X 与 αᵢ 的相关性：pooled系数容易偏离真实β，个体FE可以去掉这项稳定差异。

只改变共同年份趋势

若 X 与年份共同变化，个体FE仍可能偏；双向FE在加性共同冲击假设下可缓解。

出现时变混杂

若 Uᵢₜ 同时影响 X 与 Y，连双向FE也无法自动修复。

动手尝试：把“时变混杂”调为 0，再逐一增加“长期选择差异”和“共同时间冲击”，观察三种估计怎样变化。
06 / IDENTIFICATION MAP

FE 可以控制“过去始终不变”，却控制不了“同时变化”

稳定混杂：国家历史、地理、长期政治文化等。

时变混杂：不断变化的国际环境、冲突、重大制度改革、宏观冲击等。

对同一国家做自身比较并不等于随机试验。识别关键仍是：影响 X 的变化，是否与影响 Y 的其他变化独立？
教学模拟 · 非论文原始数据
06 / NO IDENTIFICATION

如果 X 不随时间变化呢？

例如一个国家的海陆位置在观察期内固定。

Xit − X̄i = 0

固定效应变换后，它没有剩余的单位内部变化，因此无法在标准个体FE回归中单独识别。

这不是“变量不重要”，而是数据和估计量不给它可用的变化。

07 / INFERENCE

标准误为什么需要按单位聚类？

同一国家不同时期的误差很可能相关：冲击不会在跨过12月31日的瞬间完全消失。

普通 OLS 标准误把记录当作独立，可能低估不确定性。

常见做法：对 单位 i 聚类。若处理在州/地区层面变化，聚类层级还须与误差和处理分配机制相匹配。

07 / DYNAMIC PANEL

动态面板：加入滞后因变量要谨慎

Yit = ρYi,t−1 + βXit + αi + εit

短面板下的 Nickell Bias

即使原始误差满足某些条件，去均值后的滞后因变量会与去均值后的误差相关；T 较短时动态FE存在偏差。

可能的研究方案

依据设定考虑更长时间维度、偏误校正或动态面板IV/GMM，例如Arellano–Bond；并诊断工具有效性。

此处只是预告，动态面板属于进阶专题，不与第06讲的标准DID混为一谈。

07 / TWFE CAUTION

双向固定效应不等于万能DID

连续解释变量的FE

个体和时间效应可以是一个线性条件均值模型的组成部分。

二元政策的TWFE DID

如果各地在不同年份实施政策，存在处理效应异质性和动态性时，系数可能混合不适当的比较。

现代识别方法

可根据设计考虑组别—时间ATT、异质性稳健DID、合成控制或交互固定效应。

第05讲先学“固定效应为什么能去掉稳定差异”；第06讲再系统学习DID的反事实与平行趋势。

08 / PAPER CASE

Income and Democracy：研究发现

论文报告：跨国收入与民主水平呈较强正相关；控制国家固定效应后，这种统计关联消失。

作者还报告了工具变量分析，并讨论长期历史路径可能如何塑造当代两者的共同水平。

这里讨论的是论文中报告的统计发现，并非“收入永远不会影响民主”的普遍定理。

研究问题的转变

跨国比较：
富裕国家是否更民主？

面板内部比较：
同一国家变富时是否更民主？

08 / PAPER CASE

Income and Democracy：识别假设

国家内变化的可比性

固定效应去掉稳定国家特征后，仍需判断收入变化是否受到其他时变因素共同驱动。

反向因果与共同变化

民主制度本身也可能影响收入；政策冲击和世界性事件可能同时作用于两个变量。

IV 不是自动保证因果

工具变量必须有可信的相关性、外生性和排除限制；论文提供IV分析并不意味着所有争议消失。

核心：FE 改变了“比较谁与谁”，但并未自动替研究者证明因果独立性。
08 / PAPER CASE

Income and Democracy：规格与含义

Democracyit = β · Incomeit + αi + λt + εit

此式是为课堂展示核心思路的简化面板规格，并不等同原文每个表格的完整设定；原文还涉及动态规格与工具变量。

跨国相关与国家内部的相关不是同一个比较，因此估计值发生变化并不奇怪。

解释结果时的三个边界

① 统计关联消失不自动证明“效应严格为零”。

② 不同时间长度可能对应不同的因果机制。

③ FE 仍无法替代对时变混杂和动态过程的讨论。

09 / R

R：fixest 双向固定效应

R / FIXEST
# install.packages("fixest")
library(fixest)
# df: country, year, democracy, income

# pooled OLS (cluster by country)
m0 <- feols(democracy ~ income, df, cluster = ~country)

# country fixed effects
m1 <- feols(democracy ~ income | country, df, cluster = ~country)

# country and year fixed effects
m2 <- feols(democracy ~ income | country + year,
            df, cluster = ~country)

etable(m0, m1, m2)
注意：fixest是第三方R软件包，需要先安装。示例统计推断为按国家聚类；实际设计还要考虑聚类数和处理分配层级。
