为什么前面的 FE、DID、SCM 还不够？

第05讲：FE

能消去不随时间变化的加性个体效应，但不自动消去时变混杂。

第06讲：DID

通过比较政策前后变化构造反事实；分期实施时简单TWFE可能混合不合适的比较。

第09讲：SCM

侧重少数处理单位，用供体拟合处理前轨迹；需要适当供体和较长预处理期。

什么是 TWFE 的模型承诺？

Yᵢₜ(0) = αᵢ + γₜ + Xᵢₜβ + εᵢₜ

可加结构

每个单位的差异由αᵢ固定表示；每一期冲击γₜ对所有单位按同样方式进入模型。

隐藏的风险

若同一全国冲击在不同州产生不同强度，单纯 αᵢ+γₜ 无法表达 λᵢ fₜ。

交互固定效应 IFE：让单位对时间因子反应不同

第一阶段

只利用未处理观测估计加性固定效应模型，避免将真实处理响应用于拟合 Y(0)。

Stata：可运行的传统FE基线

Stata / 面板整理 + 基线FE（不是现代DID最终估计）
clear all
set seed 20261023
set obs 40
gen id = _n
expand 12
bysort id: gen year = 2000 + _n
* 教学数据：一部分单位从2007年起接受处理
gen treat = (id <= 16 & year >= 2007)
gen alpha = id/8
gen factor = sin((year-2000)/1.8)
gen y = alpha + .45*(year-2000) + ///
        .35*(id/10)*factor + 2.5*treat + rnormal()
xtset id year
xtreg y treat i.year, fe vce(cluster id)
* 这是基线模型：交互时变混杂可使结果偏误

不需要外部软件包；上述数据完全合成，FE不是自动有效的识别策略。

R：FEct、IFEct与MC的正式实现

R / fect包 · 同一数据比较三类反事实估计器
# install.packages("fect")  # 首次运行需联网
library(fect)
set.seed(20261023)
dat <- expand.grid(id=1:40, time=1:14)
dat$D <- as.integer(dat$id <= 12 & dat$time >= 9)
alpha <- rnorm(40); loading <- rnorm(40)
factor <- sin(dat$time / 2)
dat$Y <- 7 + alpha[dat$id] + .3*dat$time +
         loading[dat$id]*factor + 2.5*dat$D + rnorm(nrow(dat),sd=.3)
# 将处理后Y(0)视为反事实缺失，仅用可用格子估计
fit_fe  <- fect(Y ~ D, data=dat, index=c("id","time"),
                method="fe", se=FALSE)
fit_ife <- fect(Y ~ D, data=dat, index=c("id","time"),
                method="ife", r=1, se=FALSE)
fit_mc  <- fect(Y ~ D, data=dat, index=c("id","time"),
                method="mc", se=FALSE)
summary(fit_fe); summary(fit_ife); summary(fit_mc)
plot(fit_ife)

真实研究必须设置适当推断与交叉验证，比较多种模型的预测诊断；方法选项以已核对的fect文档为依据。

library(did)

              gname="g", data=dat, panel=TRUE,
              control_group="nevertreated")
