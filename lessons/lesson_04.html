01 / THE PROBLEM

匹配不是“找一个相似的人”那么简单

假设参加职业培训的人，平均工资高于未参加者。

差异至少包含两部分：培训的效应，以及参加培训前就存在的群体差异。

观察到的差异 = ATT + 选择偏差

匹配和加权尝试从观察性数据中重新建立处理前的可比性。

01 / FROM THE DAG

先问：哪些变量必须在处理前调整？

年龄、受教育程度与既往工资，可能同时影响培训机会与未来收入。

D ← X → Y

只要这条后门路径仍开放，直接比较就可能有偏差。

匹配变量优先是有充分因果理由的处理前共同原因。不要机械纳入中介、对撞因子与处理后结果。
02 / IDENTIFICATION

两条识别假设：CIA 与共同支撑

条件独立性 CIA

(Y¹, Y⁰) ⫫ D | X

在控制处理前协变量 X 后，处理分配与潜在结果独立。

这不是由匹配成功自动证明的。

共同支撑 / Positivity

0 < Pr(D=1 | X) < 1

相同 X 的人既有可能接受处理，也有可能不接受处理。

没有可比对象的地方，不能只靠算法补出反事实。

只有识别假设成立，平衡后的比较才可作因果解释；“已经平衡”只是一项诊断结果。
02 / WHAT IS IDENTIFIED

先确定目标：ATE 还是 ATT？

ATE · 所有人平均效应

E[Y¹ − Y⁰]

如果所有人都接受处理，与所有人都不接受相比，平均差多少？

ATT · 已处理者平均效应

E[Y¹ − Y⁰ | D=1]

真正接受培训的那些人，从培训中获得多少？

匹配处理组到对照组最常自然对应 ATT。若丢掉匹配不到的处理组个体，估计对象可能改变。

02 / IDENTIFICATION LOGIC

条件均值之差何以代表潜在结果之差？

E[Y¹ − Y⁰ | X]
CIA + 一致性 →
E[Y | D=1, X] − E[Y | D=0, X]
在相应目标人群上加权平均 →
ATE 或 ATT

这里的关键不是某个匹配算法，而是把不可观测潜在结果转化为可观测条件期望所需的假设。

子分类：先分层，再做层内比较

第五章以泰坦尼克号幸存率为例：如果女性、儿童更容易存活，而头等舱乘客的性别与年龄分布不同，那么直接比较客舱等级的幸存率可能混入构成差异。

01按 X 分层

性别 × 年龄

02层内比较

处理组 − 控制组

03重新加权

使用目标人群的层权重

分层不创造随机性：在每层内部，仍必须判断是否存在其他混杂。
03 / INTERACTIVE SUBCLASSIFICATION

同样的层内效应，不同的组间构成

示意分层（而非泰坦尼克号真实数据）：高基线组 70%，低基线组 30%，两层真实处理效应均为 +10百分点。

未经调整的差异—
分层加权后的 ATE—
改变的只是组间构成；没有改变各层内部的处理效果。这说明为什么总体均值差会误导。
04 / NEAREST NEIGHBORS

近邻匹配：为每位处理者找可比的对照者

对每个接受培训者，寻找处理前特征最相近的未培训者。之后比较两人的结果。

ATT ≈ 平均(Yᵢ − Yj(i))

“相近”必须有明确距离规则，且不能忽视匹配质量。

若找不到足够接近的对象，宁可报告无法匹配，也不要强行配对。

按“下一步”观看配对线逐渐出现；概念说明不拆成逐字动画。

匹配后既往收入 SMD—

04 / BALANCE DIAGNOSTICS

匹配之后，必须检查协变量平衡

SMD = ( X̄₁ − X̄₀ ) / spooled

标准化均值差（SMD）衡量处理组和对照组在处理前特征上的差异。

常见经验标准是 |SMD| < 0.1，但这只是诊断规则，不是因果证明。

不要看匹配后的协变量显著性检验 p 值来取代平衡诊断；还应关注分布、方差比、重叠与样本损失。

演示点位由上页同一组模拟数据与选择的匹配度量实时计算。

04 / BEYOND EXACT MATCHING

如何衡量“相似”？三种常用距离

欧氏距离

√Σ(Xᵢ − Xⱼ)²

简单，但量纲不同会主导结果。

马氏距离

√(ΔXᵀΣ⁻¹ΔX)

考虑变量尺度与相关性。

倾向得分距离

|e(Xᵢ) − e(Xⱼ)|

将多维 X 汇总为一个处理概率。

无论用哪种距离，都要先判断变量是不是应该被调整，再评价共同支撑和平衡。
05 / THE PROPENSITY SCORE

倾向得分不是“结果预测概率”

e(X) = Pr(D = 1 | X)

给定处理前特征 X，一个个体接受处理的条件概率。

输入

年龄、受教育年限、处理前就业和收入等 X。

输出

0—1 之间的数，代表估计的“被处理可能性”。

常见估计方法是 logit / probit；但一个预测良好的倾向模型，不必然带来良好的协变量平衡。

05 / BALANCING THEOREM

倾向得分为什么能够“降维”？

D ⫫ X | e(X)
在 CIA 与适当共同支撑条件下 →
(Y¹, Y⁰) ⫫ D | e(X)

统计含义

原本需要匹配很多维度的 X；在倾向得分相近的单位间比较，能够利用平衡性质。

重要限制

这是建立在正确的识别假设和足够拟合/平衡基础上的结果；它无法解决重要的未观测混杂。

05 / OVERLAP LAB

谁能匹配，谁几乎没有反事实？

位于截尾区间内的样本—
被剔除比例—
处理组 对照组 截尾区域
截尾有助于避免严重外推与极端权重，但也可能改变估计对象；不能把截尾样本的效应自动称为原总体ATE。
05 / THE OVERLAP PROBLEM

共同支撑不足是一项识别问题，不是软件问题

如果 e(X) 接近 1，一个处理组个体几乎找不到同样特征的控制组个体。

近邻匹配可能要把他与很不像的人配对；IPW 可能赋予少数控制组极高权重。

正确处理：展示重叠图、解释排除范围、诊断权重，并重新说明目标人群。
06 / INVERSE PROBABILITY WEIGHTS

从匹配转向加权：IPW 的直觉

处理组的 ATE 权重

wᵢ = 1 / e(Xᵢ)

原本较少受到处理的类型，在处理组中得到较大权重。

对照组的 ATE 权重

wᵢ = 1 / [1 − e(Xᵢ)]

原本较少保持未处理的类型，在对照组中得到较大权重。

IPW 试图构造协变量分布更可比的加权总体，但极端倾向得分可能造成巨大权重。
06 / WEIGHTING LAB

把一个极端权重放大看看

若该人接受处理：ATE权重—
若该人未接受处理：ATE权重—

拖动到 e(X)≈0 或 e(X)≈1，观察反事实稀少时权重如何放大。

正式研究应报告权重分布、极端值、有效样本量（ESS）及稳定性分析。

06 / TARGET POPULATIONS

ATE、ATT、ATO 加权的目标不同

ATE

D/e，(1−D)/(1−e)

面向总体平均处理效应。

ATT

D，(1−D)e/(1−e)

让对照组更像已处理者。

ATO / Overlap

D(1−e)，(1−D)e

聚焦两种处理都有较大可能性的重叠人群。

比较方法之前，先确认研究政策真正关心的是谁的效应。

不同目标参数不可因数值接近就视为同一个；Overlap weighting 不自动估计原总体ATE。
07 / COARSENED EXACT MATCHING

CEM：先明确“差异允许多大”，再匹配

精确匹配要求每个协变量完全相同，实际研究中常因维度过多而无法匹配。

粗化精确匹配（CEM）先把连续变量划分为有意义的区间，再要求处理组与对照组落入同一个多维分层。

粗化 X → 共同分层 → 删除无匹配分层 → 加权分析
07 / CEM INTERACTIVE

粗化过细：很多人没有配对对象

保留的处理组比例—
有共同支持的分层—
处理组 对照组
分层越细，匹配质量可能更高，但样本损失也可能更严重；CEM 的结果依赖粗化规则。
08 / WHAT MATCHING CANNOT DO

匹配的三个边界

不能消除未测混杂

被观察到的 X 再平衡，也无法证明所有相关原因都已经纳入。

不能凭空产生可比对象

有些处理个体没有共同支撑，应报告其被剔除以及目标参数的变化。

不能用拟合优度替代平衡

处理预测很准的 logit 模型，未必是用于因果估计的好模型。

匹配像“研究设计中的预处理”：诊断重叠、平衡与样本保留，再使用合适的估计与不确定性评估。

09 / RESEARCH EVIDENCE

一项经典研究，也有不同的解释边界

Dehejia & Wahba (1999) · JASA

在NSW训练计划的观察性对照组比较中，论文报告：采用合理的倾向得分分层与匹配，可以得到接近实验基准的估计。

这是特定样本与设定下的经验结果，不是“倾向得分总能解决内生性”的定理。

10 / ARTICLE DISSECTION

论文发现：何谓“先界定不平衡”？

传统近邻匹配的路径

先定义距离 → 执行匹配 → 检查实际平衡 → 如果仍差，反复调算法。

CEM 的路径

先规定粗化区间 → 直接按区间精确匹配 → 已决定了可接受的粗化层面。

论文的关键贡献是讨论CEM与MIB类匹配方法的理论性质及实现工具；不能把粗化变量上的匹配理解为所有原始变量完全平衡。

10 / ARTICLE DISSECTION

识别假设：CEM无法自动满足哪些条件？

条件独立性

粗化层内仍需说明不存在重要的未观测混杂；粗化本身也可能留下残余不平衡。

共同支撑

落入仅有处理组或仅有对照组的分层将无法用于直接匹配比较。

SUTVA与时间顺序

处理需要定义明确；只能合理使用处理前协变量，不应控制处理后的变量。

更好的协变量平衡，并不能替代任何一条因果识别假设。
10 / ARTICLE DISSECTION

估计对象与CEM权重

先辨认目标总体

ATT 的目标是所有符合研究定义的已处理者。删除未匹配的处理者后，通常只能直接识别“被保留处理者”的效应，需要说明外推条件。

分层再加权

CEM在匹配分层内重新比较两组，并按所选目标参数分配权重，以免因为每层处理/对照比例不同而让组构成失衡。

ATTmatched = Σs [N1s / N1,matched] · (Ȳ1s − Ȳ0s)

这是在共同分层内、按保留处理组构成汇总差值的简化ATT估计形式，仍依赖识别假设。

11 / STATE OF THE ART

2024年的方法提醒：更关注重叠与极端权重

Overlap weighting

更强调处理概率居中的个体，有时能够改善权重稳定性，并把效应目标明确转向“重叠人群”。

2024：Overlap weighting 方法综述 ↗

Target trial emulation

在做倾向得分前先确定纳入标准、处理定义和时间起点，防止“匹配得很漂亮却比较错了问题”。

2024：方法系统综述 ↗

更新的技术不是取消CIA，而是更加重视：目标参数、可比性、时间设计、透明诊断。
11 / METHODS IN 2025–2026

新进展：不止“估计一个倾向得分”

2026：直接优化协变量平衡

2026年Statistics in Medicine的模拟研究比较 IPW、CBPS、energy balancing 与 kernel optimal matching，指出有限样本表现取决于处理比例、重叠条件与具体实现。

2026年比较研究 ↗

2025：不要混淆 ATO 和 ATE

Journal of Clinical Epidemiology的方法评论强调：Overlap weighting估计的是重叠人群的平均效应，不能仅因为ATE权重不稳定，就换成ATO后宣称解决了原问题。

2025年方法评论 ↗
趋势是从“匹配算法选哪一个”转向“目标效应是什么、协变量是否真正平衡、哪些人有可靠比较”。

12 / R WORKFLOW

R：MatchIt + cobalt诊断平衡

R · 自包含教学数据 
# 第04讲：教学模拟数据（非论文原始数据）
set.seed(2404)
n <- 600
age <- sample(18:57, n, TRUE)
prior <- 2 + .16*age + 4*rnorm(n)
p <- plogis(-1 + .04*age + .12*prior)
d <- rbinom(n, 1, p)
y <- 5 + .5*prior + .04*age + 2*d + rnorm(n)
dat <- data.frame(age, prior, d, y)

# install.packages(c('MatchIt','cobalt'))
library(MatchIt)
library(cobalt)
m <- matchit(d ~ age + prior, data=dat,
             method='nearest', estimand='ATT')
summary(m, standardize=TRUE)
love.plot(m, threshold=.1, abs=TRUE)
md <- match_data(m)
weighted.mean(md$y[md$d==1], md$weights[md$d==1]) -
  weighted.mean(md$y[md$d==0], md$weights[md$d==0])
# 上式仅为估计值演示；完整推断需选匹配适配的方差估计。

这讲要记住的三句话

01 匹配和加权构造的是可观察特征上的可比性，不自动解决未观测混杂。

02 任何方法都必须先明确目标人群与共同支撑。

03 好的匹配研究报告的不是“匹配成功”四个字，而是设计、平衡、样本变化与识别边界。
