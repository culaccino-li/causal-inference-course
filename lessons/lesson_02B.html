调查实验的三个典型用途

Frame / Vignette

随机改变政策信息、身份标签或措辞，比较态度变化。

List Experiment

对敏感态度使用间接计数，减少受访者直接表态压力。

Conjoint

同时随机多个属性，分辨哪些政策方案或候选人特征影响选择。

调查随机化有助于识别“题目刺激”的因果效应，不等于现实行为一定同样改变。

调查实验的识别对象是什么？

题干处理

受访者看到的情景文字、候选人属性或信息框架。

观察结果

支持度、选择、评价打分；通常是态度或陈述偏好。

外推限制

在线问卷场景与真实投票、移民政策行为的差别，需要单独讨论。

Vignette：单一政策信息框架

对照组：“市政府拟调整公共交通补贴政策”。

处理组：“市政府拟调整公共交通补贴政策，预计可降低低收入家庭通勤成本”。

测量：受访者是否支持此政策。

识别：随机分配不同题干后，两组支持率之差。

警惕：受访者可能不仔细阅读；题干同时改变两个线索，便不能分辨各自效应。

列表实验：不用说出敏感项是什么

控制组：告诉调查者自己同意多少条“普通”陈述，而不是哪几条。

处理组：看到相同普通陈述，加上一条敏感陈述，同样只报告同意的总数量。

πsensitive = E[Count | T=1] − E[Count | T=0]
关键假设：新增敏感项不改变其他普通项的回答，且不会使受访者故意隐瞒计数。

列表实验不是魔法：设计效应与地板效应

无设计效应

添加敏感项不改变普通项的回答；否则两组均值差混入其他题变化。

无策略性误报

敏感态度受访者不故意调低自己的计数。

避免天花板与地板

普通项让所有人都回答0或全部时，敏感项可能暴露，引发误报。

认识AMCE、边际均值与相对参照

AMCE

把某属性从参照水平改为目标水平，在其他随机属性分布上取平均的因果效果。

Marginal Means

一个属性水平出现时的平均结果；不依赖人为选择的参照水平。

不能解释为人群偏好率

AMCE是相对效应，受到属性分布、情境和参照水平影响。

Conjoint实验的随机化约束

禁止不可能组合

例如政策设计有法律约束时，要明示哪些属性水平不能搭配。

代价

约束可能使属性独立随机化失效；AMCE的条件平均含义改变。

实践

保存随机化器和所有可行配置，检查各属性水平分配频数。

真实AJPS论文：美国人的移民偏好

Hainmueller & Hopkins（2015），American Journal of Political Science 59(3):529–548。

通过人口调查中的Conjoint任务随机呈现移民申请者多个属性，研究哪些特征影响入境支持。

研究报告：教育程度高、职业地位较高的申请者相对更受欢迎；若无工作计划、缺乏英语能力等则相对不受欢迎。

论文官方 DOI ↗

识别优势：在同一个随机化方案中区分多项属性的贡献。

解释限制：这是问卷中的入境支持偏好，不应直接等同于现实政策行为。

论文发现｜隐藏的移民政策偏好共识

主要发现

R｜Conjoint模拟数据与聚类稳健推断

R · 可运行合成示例
set.seed(2026)
id <- rep(1:120, each = 6)
n <- length(id)
skill <- sample(0:1, n, TRUE)
language <- sample(0:1, n, TRUE)
legal <- sample(0:1, n, TRUE)
y <- rbinom(n, 1, plogis(-.7 + .35*skill + .3*language + .45*legal))
d <- data.frame(id, y, skill, language, legal)
fit <- lm(y ~ skill + language + legal, data=d)
# cluster-robust SE if packages installed:
# sandwich::vcovCL(fit, cluster = d$id)
summary(fit)
# 这是简化的独立profile二元结果模拟；真实强制二选一

识别

解释

结果不自动外推到所有地区、选民或现实政策环境。
